# Поиск автозапчастей

Клиентское приложение на React + Redux Toolkit для сервиса «Проценка» Фаворит Автозапчасти
([документация API](https://lk.favorit-parts.ru/static/wsprice.pdf)).

Подбор идёт в два этапа:

1. Пользователь вводит артикул — приложение находит производителей, которые выпускают деталь с этим номером.
2. Пользователь выбирает производителя — приложение показывает саму деталь и её аналоги: производитель, номер,
   название, склад и дату отгрузки, остаток и цену.

Поиск по артикулу — основной и полный. Поиск по названию или производителю — вспомогательный, по
встроенному справочнику, без гарантии полноты (подробнее в [ARCHITECTURE.md](ARCHITECTURE.md)).

Стек: React 19, Redux Toolkit, Bootstrap 5, Vite. Без TypeScript.

## Языки

Интерфейс на русском и английском, переключатель — в шапке. **Русский — язык по умолчанию,
так задумано**: приложение открывается по-русски независимо от языка браузера. Выбранный язык
запоминается, а ссылкой с `?lang=en` можно сразу открыть английскую версию.

В английской версии поиск по артикулу или производителю: производители в данных записаны
латиницей, а названия деталей — по-русски, поэтому поиск по названию там не предлагается.
Названия деталей и коды складов приходят из API по-русски и не переводятся.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Ключ API задаётся в файле `.env.local` (образец — `.env.example`):

```
FAVORIT_API_KEY=ваш-ключ
```

После изменения `.env.local` перезапустите `npm run dev`.

## Как это устроено

Браузер не обращается к API напрямую. Запросы идут на `/api/search` dev-сервера Vite, а тот пересылает их
на `api.favorit-parts.ru` и подставляет ключ (см. `vite.config.js`). Так:

- нет проблем с CORS и с тем, что API работает по HTTP;
- ключ не попадает ни в браузер, ни в собранный бандл, ни в git;
- прокси пропускает к API только параметры `number`, `brand` и `analogues`.

Для деплоя понадобится такой же прокси на сервере (например, serverless-функция). Его адрес задаётся
переменной `VITE_API_URL`, код фронтенда при этом не меняется.

## Структура

```
src/
  api/favorit.js           запросы к API и разбор ответа
  catalog/                 справочник названий: seed.json + самообучение в localStorage
  i18n/                    словари ru.js и en.js, translate() и хук useT()
  store/searchSlice.js     состояние поиска, thunk'и searchByName, fetchBrands, fetchOffers
  store/filtersSlice.js    фильтры и сортировка предложений
  store/urlSync.js         состояние поиска и язык в адресной строке
  store/langSlice.js       выбранный язык
  store/catalogListener.js самообучение справочника по ответам API
  store/index.js           configureStore
  components/
    SearchForm.jsx         поле артикула или названия, автопоиск после паузы в вводе
    NameResults.jsx        детали из справочника по названию
    BrandList.jsx          этап 1: список производителей
    OffersTable.jsx        этап 2: таблица предложений и аналогов
    OfferFilters.jsx       фильтры и сортировка предложений
    Loader.jsx             индикатор загрузки
    ErrorAlert.jsx         сообщение об ошибке с кнопкой «Повторить»
  utils/format.js          цена, дата отгрузки, нормализация артикула
scripts/build-seed.mjs     одноразовый сбор стартового справочника через dev-прокси
```

## Состояния и ошибки

У каждого этапа свой статус: `idle → loading → succeeded | failed`.

| Ситуация | Что видит пользователь |
|---|---|
| Идёт запрос | спиннер |
| Нет связи с API | «Сервис недоступен…» и кнопка «Повторить» |
| API не ответил за 15 секунд | сообщение о таймауте и «Повторить» |
| API вернул `{"error": …}` | понятный текст: неверный ключ, превышен лимит запросов и т. д. |
| Деталь не найдена (API возвращает массив с пустой структурой) | «ничего не найдено» |
| У предложения нет остатка | строка серым цветом, пометка «нет в наличии» |

Если пользователь начал новый поиск, ответ на старый запрос игнорируется.

Цена и остаток берутся из массива `warehouses`, по строке на каждый склад: поле `price` у самой детали
документация просит не использовать.
